把社群上看到的餐廳與景點，變成你自己的口袋名單

PinPost 是一個 iOS App。當你在 Instagram、Facebook 或 Threads 上看到朋友、 美食帳號分享的餐廳或景點貼文時，用系統的「分享」功能傳給 PinPost， 就能自動整理成一份可以隨時回顧的清單。

分享即收藏

從 Instagram / Facebook / Threads 直接分享連結到 PinPost，不用手動抄店名地址。

自動整理資訊

解析貼文的作者、說明文字與縮圖，並嘗試從文字中辨識店名與地址。

資料留在你手機上

收集到的內容儲存在你自己的裝置上，不會用於廣告或第三方分析。

運作方式

PinPost 使用 Meta 官方提供的 oEmbed API，讀取你主動分享進來的 公開貼文資訊（作者名稱、說明文字、縮圖），不會存取你的 Instagram、 Facebook 或 Threads 帳號本身，也不需要你登入這些帳號。

聯絡方式

如有任何問題，歡迎透過 GitHub repository 與我們聯絡。
